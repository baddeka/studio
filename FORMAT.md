# File formats

For anyone (a person or another Claude) who prepares material for a video by hand instead of letting `vp run` make it. Put the files in `videos\<slug>\` and run `.\vp run <slug>`: steps whose output already exists are skipped, everything after them is generated.

## 01_research.md

Free Markdown. It must end with a `## Sources` section, one source per line:

```
## Sources
[1] SEC v. Samuel Bankman-Fried, complaint - SEC - 2022-12-13 - https://www.sec.gov/...
[2] FTX files for bankruptcy - Reuters - 2022-11-11 - https://www.reuters.com/...
```

Facts in the body carry the numbers in brackets, like `[2]`. The fact-check step checks the script against this file.

## 02_script.md

```
# Working title

## Part 1: Cold open
Narration paragraph. Two to five sentences.

Another paragraph.

## Part 2: The promise
...
## Part 7: The lesson
...
```

- Exactly 7 parts, headings `## Part N: Title`. The title after the colon becomes the YouTube chapter name.
- Only narration under the headings: no bullet points, bold, brackets or stage directions. A paragraph wrapped in `[ ]` or a line starting with `>` is treated as a note and not read aloud.
- Written to be spoken: "$8 billion", "percent" instead of %, no symbols.
- About 3,500 words for a 23-minute video.

## 04_shotlist.json

Normally generated by `.\vp shotlist`. The script is split into numbered beats (one sentence or clause, 6-16 words); each scene covers 1-2 consecutive beats, about 4-6 seconds.

```json
{
  "version": 1,
  "script_hash": "...",
  "parts": [{"n": 1, "title": "Cold open"}],
  "beats": [{"id": 1, "part": 1, "para": 0, "w0": 0, "w1": 9, "text": "On November 8, 2022, the withdrawals stopped."}],
  "scenes": [
    {"id": "S1-01", "part": 1, "beats": [1], "type": "still", "visual": "Empty trading floor at night",
     "camera": "push_in", "onscreen": "Nassau, Bahamas - 2022",
     "mj_prompt": "an empty open-plan trading floor at night, rows of dark monitors ...",
     "mj_full": "... cinematic film still, ... --ar 16:9 --style raw"},
    {"id": "S1-02", "part": 1, "beats": [2], "type": "card",
     "card": {"kind": "stat", "text": "$8,000,000,000", "sub": "of customer money missing", "items": [], "tone": "loss"}},
    {"id": "S1-03", "part": 1, "beats": [3, 4], "type": "motion", "mj_prompt": "...", "mj_full": "...",
     "kling_prompt": "slow dolly in, rain streaks on the glass, screens flicker"},
    {"id": "S1-04", "part": 1, "beats": [5], "type": "reuse", "reuse_of": "S1-01", "camera": "pan_left"}
  ]
}
```

- `type`: `still` (Midjourney image + automatic camera move), `motion` (Midjourney image animated in Kling), `card` (rendered automatically), `reuse` (an earlier image with another camera move).
- `camera`: `push_in`, `pull_out`, `pan_left`, `pan_right`, `pan_up`, `pan_down`, `static`.
- `card.kind`: `stat`, `quote`, `date`, `title`, `text`, `document`, `list`, `compare`; `tone`: `neutral`, `loss`, `gain`, `alert`.
- Scene ids are per part (`S3-07` is scene 7 of part 3). Image and clip files use the id as the name: `assets\images\S3-07.png`, `assets\clips\S3-07.mp4`.
- Midjourney prompts never contain real names, logos or text; real people are stylized, faceless figures.
